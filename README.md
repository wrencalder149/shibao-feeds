# 時報 RSS（新版）

在 RSS 閱讀器「加入訂閱」，整段貼上（建議用 jsDelivr，較少舊快取）：

- 快訊（當日一則／內含 13–16 篇短文）  
  https://cdn.jsdelivr.net/gh/wrencalder149/shibao-feeds@main/briefs.xml
- 深度（全文繁中，4–5 則）  
  https://cdn.jsdelivr.net/gh/wrencalder149/shibao-feeds@main/deep.xml
- 文化（全文繁中，4–5 則）  
  https://cdn.jsdelivr.net/gh/wrencalder149/shibao-feeds@main/culture.xml

**分享／TTS 請開各則連結（HTML 全文頁）**，路徑為 `html/{channel}/{slug}.html`；**訂閱仍用上方三個 xml**。

**請勿再使用舊的薄稿／raw.githubusercontent.com 快取連結，也勿依賴 xml#slug 當分享頁。** 若閱讀器仍顯示舊內容，改訂上方 jsDelivr 網址並強制刷新。
